# Prompts

Standalone prompts and checklists to run in another PC environment. Each one says what to read
and what to bring back; none needs this repository's skills.

- `rating-access-report.md` — produce a rating access report for one line: the object tree the
  engine rates, every write and its backing, every entity-backed field read, runtime evidence.
- `rating-access-inputs-checklist.md` — what to gather from an environment before running the
  extraction chain and the access report.
